findex — Lab 01: Iterators, Generators and Corpus

Тема проєкту
Базова частина пошукової системи (findex). Реалізовано лінивий конвеєр читання текстового корпусу через генератор (iter_documents()) та токенізацію слів через (tokenize()).

Порівняння продуктивності
Підхід                     Пікова пам'ять  | Час виконання 
Генератор (Lazy / yield)   ~27.20 KB       | ~0.0012 c 
Список (Greedy / append)   ~9.36 KB        | ~0.0004 c 

Висновки:
Витрати в малому обʼємі:На 3 документах жадібний список споживає менше пам'яті через відсутність службового навантаження генератора Python на збереження стану фрейму.
Масштабування:При зростанні обсягу корпусу до 50 МБ жадібний підхід потребує більше оперативної пам'яті, що завантажує всю базу одночасно. Генератор з (yield) утримує стабільне споживання, відносно кількості файлів, оскільки одночасно в пам'яті перебуває тільки один документ.
