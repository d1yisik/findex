# findex — Інвертований індекс (Лабораторна робота №2)

Модульний інвертований індекс для повнотекстового пошуку на Python з підтримкою булевих операцій (`AND`, `OR`, `NOT`) та двома алгоритмами пошуку (`merge` та `set`).
## Структура проєкту

- `src/findex/models.py` — моделі даних `Posting` та `DocMeta` з оптимізацією пам'яті через `__slots__`.
- `src/findex/builder.py` — побудова індексу в один прохід (`Counter`, `defaultdict`), методи збереження/завантаження (`pickle`, `json`).
- `src/findex/search_engine.py` — булевий пошуковий рушій (two-pointer `merge` та множини `set`).
- `src/findex/index.py` — CLI для побудови та збереження індексу з трекінгом пам'яті.
- `src/findex/search.py` — CLI для виконання булевих запитів.
- `benchmark.py` — скрипт порівняння швидкості серіалізації та рушіїв пошуку.
- `memory_bench.py` — скрипт бенчмарку пам'яті для різних структур зберігання постінгів.
